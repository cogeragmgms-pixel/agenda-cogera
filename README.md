# Agenda COGERA

App instalável (PWA) da agenda dos técnicos da equipe GMG.

- A programação vem do **Painel MS** e é guardada numa planilha Google pelo **Apps Script**.
- Este site mostra a página do Apps Script em tela cheia e lembra o código de cada técnico.
- Link de cada técnico: este endereço + ?t=CODIGO (os códigos ficam no painel, em **App técnicos**).
- enviar.html é a ponte que entrega a programação do painel ao Apps Script.

Arquivos: index.html (app), enviar.html (envio), manifest.webmanifest e ícones (instalação), sw.js (abre rápido com internet fraca).
